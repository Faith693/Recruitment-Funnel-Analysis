# 📊 Recruitment Funnel Analysis

## 🧩 Business Problem
Organizations often struggle to understand inefficiencies in their recruitment process. This project analyzes the recruitment funnel to identify bottlenecks, improve hiring efficiency, and reduce time-to-hire.

---

## 📁 Dataset
The dataset includes:
- Candidate stages (Applied, Interview, Offer, Hired)
- Recruitment sources
- Time-to-hire
- Candidate drop-off rates

---

## 🛠 Tools Used
- SQL (Data extraction and transformation)
- Power BI (Dashboard and visualization)

## 🔍 Key Insights
- Significant drop-off observed at the interview stage
- Certain recruitment sources produce higher-quality candidates
- Time-to-hire varies significantly across roles
- Bottlenecks identified in candidate screening process

---

## 💡 Recommendations
- Improve interview process efficiency
- Focus on high-performing recruitment channels
- Streamline candidate screening stages
- Implement structured hiring timelines

---

## 📌 Conclusion
This analysis helps identify inefficiencies in the recruitment pipeline and provides actionable insights to improve hiring outcomes.
